**Goal:** Ship 1.7.0. It includes everything on the unreleased `feat/1.6.5-polish` branch, plus:

**Tech Stack:** Swift 6 (default MainActor), SwiftUI, deployment target iOS 26.0, **Xcode 27.1 / iOS 27.1 SDK required to build** (for `ArrangementView` and `ReservedRegion`), Swift Testing, XCTest, `scripts/strings.py`.

### Task 11: Narrow-group rebuild caution

**Files:** `RaidCalculator.swift`, `RaidCalculatorViewModel.swift`, `ContentView.swift`, strings, tests, `www/index.html` and `README.md`.

Todd's decision: narrow RAID 50 or RAID-Z1 groups on drives of 8 TB or more should warn even when no safer level fits.

- [ ] **Step 1: Unit tests** in the RAID calculator tests:
  - `narrowGroupsWarnWithoutSuggestion`: RAID 50 with 6 × 12 TB in 2 groups gives `rebuildCaution(for:) == .warnOnly`.

- [ ] **Step 2: Implement.** Replace `rebuildCautionSuggestion(for:) -> RaidLevel?` with:

```swift
enum RebuildCaution: Equatable {
    /// A dual-parity level this setup's groups are wide enough to become.
    case suggest(RaidLevel)
    /// Large drives on single parity, but the groups are too narrow for the
    /// dual-parity level; warn without a suggestion.
    case warnOnly
}

/// Single-parity layouts on drives of 8 TB or more: a rebuild takes days,
/// and a second failure during it loses the array.
func rebuildCaution(for config: RaidConfiguration) -> RebuildCaution? {
    guard validate(config) == nil else { return nil }
    let terabytes = config.unit == .tb ? config.driveSize : config.driveSize / 1000
    guard terabytes >= 8 else { return nil }
    let safer: RaidLevel
    switch config.level {
    case .raid5: return .suggest(.raid6)
    case .raid50: safer = .raid60
    case .raidz1: safer = .raidz2
    default: return nil
    }
    return config.driveCount / groupCount(config) >= safer.minimumGroupWidth ? .suggest(safer) : .warnOnly
}
```

Update `ContentView`: `.suggest` shows the existing text plus Task 9's button, and `.warnOnly` shows a new key `rebuild_caution_narrow`, “Rebuilding %@ on drives this large can take days, and a second failure during the rebuild loses the array. Wider groups would allow dual parity.”, with no button.
- [ ] **Step 3: Copy.** In `www/index.html` and `README.md`, the rebuild sentence becomes: “RAID 5, RAID 50 and RAID-Z1 on drives of 8 TB or more warn that a rebuild can take days and that a second failure during it loses the array, and suggest RAID 6, RAID 60 or RAID-Z2 when the groups are wide enough to move up.”
